1파일 넣기

파일을 여기에 끌어 놓기 또는 눌러서 선택
엑셀 · 워드 · PPT · PDF · 한글(HWP·HWPX) · 사진(JPG·PNG)

사전·무시 목록·띄어쓰기 설정을 바꾸면 자동으로 다시 검사하고, 이미 고른 선택은 그대로 둬요.

!더 정확하게 하려면 (AI 검사)

지금 검사는 이 PC 안에서 무료로 돌아가는 대신 정확도에 한계가 있어요. 특히 사진·스캔 파일은 글자를 잘못 읽어서 엉뚱한 오타가 나올 수 있어요.

개인 API(Claude 같은 AI 서비스) 키를 연결하면 사진 속 한글을 정확하게 읽고, 문맥까지 보고 맞춤법을 검사할 수 있어요.

  • 파일 내용이 외부 서버로 전송돼요 → 학생 개인정보 규정을 먼저 확인해 주세요
  • 쓴 만큼 요금이 나와요(문서 한 건에 몇십~몇백 원 수준)
키 받는 방법
  1. console.anthropic.com 에 가입하고 결제 수단·크레딧을 등록해요(월 사용 한도도 걸 수 있어요)
  2. 「API Keys」 → 「Create Key」를 눌러 sk-ant-… 키를 복사해요
  3. 위 칸에 붙여 넣고, 파일을 넣은 뒤 「AI로 한 번 더 검사」를 눌러요

키는 이 브라우저에만 있고 사이트 코드(GitHub)에는 들어가지 않아요. 공용 PC에서는 쓰고 나서 「키 지우기」를 눌러 주세요. 버튼을 누를 때만 그 파일의 글(사진은 그림)이 Anthropic으로 전송돼요. 사진은 가리기를 할 수 없어요.

국어사전 확인 (국립국어원, 무료)

문서 속 낱말의 원형(수첩을 → 수첩, 만들었다 → 만들다)을 표준국어대사전·우리말샘에서 찾아, 사전에 없는 말을 「확인 요망」으로 보여 줘요. 문장은 보내지 않고 한글 낱말만 보내요(이름·숫자·영어 제외).
외래어(글로벌·멘토·솔루션)·이름·줄임말은 사전에 없을 때가 많아 「국어사전(외래어·이름)」으로 따로 묶고 기본은 「빼기」로 둬요.

2결과 고르기

수정 필요 틀린 게 거의 확실 · 확인 요망 틀렸을 수 있어 사람이 확인 · 오탈자·형식 철자·띄어쓰기·공백·괄호. 숫자 칸을 누르면 목록에서 숨기거나 다시 보여요.

각 항목 오른쪽에서 내보낼 때 처리 방법을 골라요: 자동 수정(고치고 초록색) · 표시만(안 고치고 색칠·메모) · 빼기.

오타 사전 고치기

한 줄에 하나씩 틀린말 → 맞는말로 적어 주세요. 화살표 대신 -> 나 = 로 써도 돼요(예: 몃일 = 며칠). 결과 카드의 「사전에 추가」로도 넣을 수 있어요. 이 브라우저에 저장돼요.

무시 목록 (0개)

결과 카드의 「다음부터 무시」로 넣은 항목이에요. 같은 내용은 다른 파일에서도 안 나와요. 줄을 지우고 저장하면 다시 나와요.

켤 때마다 검사 도구(약 100MB)를 불러와요. 처음엔 1~2분, 그다음엔 브라우저에 저장돼 있어 빨라요. 제안은 빼기로 나오고, 직접 고른 것만 고쳐져요.

영어 사전(약 0.5MB)으로 철자를 봐요. 대문자 약어(KMCU), 이름 칸, 파일 안에서 3번 이상 쓰인 단어(학교·회사 이름 등)는 넘어가요. 제안은 빼기로 나오고, 직접 고른 것만 고쳐져요.

3자동 수정·내보내기

자동 수정 0개 · 표시만 0개 · 빼기 0개

파일을 보낸 곳에 돌려보내 직접 고치게 할 때 켜세요.

맨 뒤에 「검수 결과」 시트(워드는 문서 끝 목록, PPT는 맨 뒤 결과 슬라이드)와 색 안내가 붙어요. 원본 파일은 바뀌지 않습니다.

왼쪽에 파일을 넣어 주세요

서식이 달라도 같은 파일 안에서 서로 비교해서 찾아요.

  • 같은 줄 대조: 성명·생년월일·보호자 이름 철자
  • 같은 칸 비교: 다른 줄엔 다 있는데 빠진 항목, 빈 값, 중복 항목
  • 공문서 규칙: 기안문(수신·제목·끝.)으로 보이면 함께 검사할지 물어봐요. 항목기호 순서(1. → 가. → 1) → 가) → (1) → (가)), 연도 있는 날짜「2026. 11. 9.」·시각「14:00」 형식, 「끝.」 표시(「행정업무의 운영 및 혁신에 관한 규정」 기준)
  • 숫자·계산: 금액 숫자↔한글(금100,000원(금십만원)), 요일(9.30.(금) → 그해 9월 30일은 수요일), 표의 합계·소계·총계 줄과 칸(엑셀 수식 범위 포함), 환율·단위(원 = 원), 평균·결석·합계, 날짜·기간
  • 오탈자·형식: 오타 사전, 한 글자만 다른 말, 율/률(가입율 → 가입률), 영어 약자 뒤바뀜(RIES → RISE), 날짜 표기 통일(9.16(수) → 9.16.(수)), 11:00시, 괄호 짝, 앞뒤 공백
  • 띄어쓰기: Kiwi 검사를 켜면 띄어쓰기 제안
  • 영어 철자: 영어 사전에 없는 단어에 고칠 말 제안 (예: Universtiy → University)
  • 문서 보기: 오른쪽에 파일이 그대로 보이고, 틀린 곳이 색칠돼요
  • 내보내기: 고른 것만 자동으로 고치고, 나머지는 색칠·메모로 표시해요
  • PDF·한글(HWP·HWPX): 고칠 수는 없어서, 오른쪽 화면에 틀린 곳만 표시해요
  • 사진·스캔 파일: 사진 속 글자를 읽어(OCR) 검사해요. 정확도에 한계가 있어요

‘-’, ‘/’ 같은 「내용 없음」 표시와 ‘1)’, ‘가)’ 같은 번호는 오류로 보지 않아요.
